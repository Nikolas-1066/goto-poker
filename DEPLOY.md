# Запуск табло в клубе (Timeweb Cloud + ТВ-приставка)

Схема: приложение работает на сервере Timeweb. Телевизор открывает табло
через приставку, админка открывается с телефона. Ноутбук не нужен.

```
Телефон (/admin) ──┐
                   ├──► VDS Timeweb (табло + база) ◄── ТВ-приставка (/)
Ноутбук (правки) ──┘         ▲
     ./deploy/push.sh ───────┘
```

## 1. Сервер в Timeweb Cloud

1. timeweb.cloud → «Облачные серверы» → «Создать».
2. ОС: **Ubuntu 24.04**. Регион: ближайший к Воронежу (Москва / Санкт-Петербург).
3. Конфигурация: **1 vCPU, 2 ГБ RAM, 15+ ГБ NVMe** — этого хватит с запасом.
4. Авторизация — по паролю (скрипт сам добавит ключ с Mac) или сразу ваш SSH-ключ.
5. Создать, записать **IP-адрес** и пароль root.

## 2. Домен (рекомендуется)

Нужен для HTTPS: без него браузер не даёт табло держать экран включённым.

- Купить домен в Timeweb («Домены») или использовать имеющийся.
- В DNS создать **A-запись**, например `tablo` → IP сервера.
  Получится `tablo.вашдомен.ru`. Запись начинает работать от нескольких минут до пары часов.

Без своего домена можно стартовать сразу: скрипт предложит адрес вида
`IP-с-дефисами.sslip.io` — он бесплатно указывает на ваш сервер, HTTPS тоже будет.

## 3. Установка (один раз, с Mac)

В терминале, в папке проекта:

```bash
./deploy/setup.sh root@IP_СЕРВЕРА
```

Скрипт:
1. добавит SSH-ключ Mac на сервер (один раз спросит пароль root);
2. спросит домен, e-mail для сертификата и **пароль админки**;
3. поставит Node.js, nginx, HTTPS, файрвол, автозапуск и ежедневный бэкап базы;
4. загрузит код, соберёт и запустит табло.

В конце покажет адрес: `https://tablo.вашдомен.ru`.

## 4. Обновление после правок

```bash
./deploy/push.sh
```

Код загрузится, соберётся, сервис перезапустится (~1–2 минуты).
Табло на ТВ само перезагрузится в новую версию — но не посреди уровня,
а на паузе или перерыве. База турниров и пресеты при обновлении не трогаются.

## 5. Телевизор

**Вариант А — Android TV-приставка (рекомендуется).**

1. Установить **Fully Kiosk Browser** (Google Play или fully-kiosk.com).
2. Настройки:
   - Start URL: `https://tablo.вашдомен.ru/`
   - Web Auto Reload → включить перезагрузку при обрыве сети;
   - Device Management → **Keep Screen On**, **Launch on Boot**;
   - Web Content Settings → **Autoplay Videos / Audio** — чтобы звук включался без клика.
3. Перезапустить приставку: табло откроется само, на весь экран и со звуком.

**Вариант Б — мини-ПК / старый ноутбук, который стоит у ТВ.** Chrome в режиме киоска:

```
chrome --kiosk --autoplay-policy=no-user-gesture-required https://tablo.вашдомен.ru/
```

(добавить в автозагрузку).

**Вариант В — встроенный браузер Smart TV.** Работает, но ненадёжно: старый движок,
телевизор может уходить в сон, звук включается только кнопкой «Включить звук».

Звук идёт через телевизор — громкость регулируется пультом.

## 6. Телефон

Откройте `https://tablo.вашдомен.ru/admin` → войдите → «Поделиться» →
**«На экран Домой»**. Админка будет открываться как приложение с логотипом клуба.

## Полезное на сервере

```bash
ssh root@IP
systemctl status goto-poker          # работает ли табло
journalctl -u goto-poker -n 100      # логи
nano /etc/goto-poker.env             # пароль админки (ADMIN_PASSWORD=...), токен бота (TELEGRAM_BOT_TOKEN=...),
                                     # адрес сайта для мини-приложения (PUBLIC_URL=https://домен)
systemctl restart goto-poker         # применить
ls /var/backups/goto-poker           # ежедневные копии базы (60 дней)
```

База: `/var/lib/goto-poker/goto-poker.db` (SQLite; старый `goto-poker.json` при первом
запуске новой версии переносится в неё автоматически и переименовывается в `.migrated`).
Программа сама делает копии в `/var/lib/goto-poker/backups/` при запуске и после каждого
турнира (последние 30), а ежедневный cron складывает свежую копию в `/var/backups/goto-poker`.

Восстановить из копии:

```bash
systemctl stop goto-poker
rm -f /var/lib/goto-poker/goto-poker.db /var/lib/goto-poker/goto-poker.db-wal /var/lib/goto-poker/goto-poker.db-shm
cp /var/backups/goto-poker/goto-poker-ДАТА.db /var/lib/goto-poker/goto-poker.db
chown goto:goto /var/lib/goto-poker/goto-poker.db
systemctl start goto-poker
```

## Если в клубе пропал интернет

Таймер на ТВ продолжит идти сам (время считается в браузере), внизу появится
«НЕТ СВЯЗИ С СЕРВЕРОМ». Управлять с телефона можно через мобильный интернет —
админке всё равно, откуда идут команды. Когда сеть вернётся, табло синхронизируется само.
