# План: система управления клубом ГОТО ПОКЕР

Ориентир — функции ELO Club (eloclubcrm.store): CRM игроков, турниры по игрокам, серии и рейтинги
ELO/CP/KO, финансы смены, бар, приложение игрока. Повторяем **не всё**, а по этапам —
то, что реально нужно клубу. Всё работает на ноутбуке в баре, офлайн.

## Этап 0 — подготовка (сделать первым)
- [ ] Перенос хранилища на SQLite (`node:sqlite`, без нативных модулей) со схемой и миграциями;
      автоматический перенос данных из `data/goto-poker.json` (пресеты + текущий турнир).
- [ ] Тесты для чистой логики (vitest): `clock.ts` + всё новое (итоги, рейтинг).
- [ ] Резервная копия базы: при каждом запуске/закрытии турнира копия в `data/backups/` (хранить 30).

## Этап 1 — игроки и турнир по игрокам (ядро)
- [ ] База игроков: имя/ник, телефон или Telegram (необязательно), заметка, дата первого визита.
      Быстрый поиск, добавление нового игрока за 5 секунд прямо из турнира.
- [ ] Участники турнира: регистрация из базы → вход, ребай, аддон, двойной аддон по игроку;
      вылет с автоматическим местом (кто вылетел раньше — ниже место); кто выбил (для KO).
- [ ] Счётчики табло (входы/в игре/ребаи/аддоны) считаются из участников автоматически
      (старый ручной режим оставить как запасной).
- [ ] Итоги турнира: таблица мест, сохраняется в истории; турнир можно открыть и исправить итоги.
- [ ] Всё удобно с телефона (админ ходит по залу).

## Этап 2 — серии и рейтинг
- [ ] Серии (лиги) с правилами: какие показатели считаются (CP, баллы за места, KO, посещения),
      период, какие турниры входят. Один турнир — в нескольких сериях.
- [ ] Начисление CP/баллов по правилам серии. **Формулы согласовать с владельцем** (предложить
      варианты: фикс. таблица мест / формула от размера поля / CP-пул от входов и аддонов).
- [ ] ELO-рейтинг игроков по результатам турниров (многопользовательский ELO, параметры — в настройках).
- [ ] Страницы рейтинга: по серии, за месяц, за всё время; карточка игрока с историей.
- [ ] Табло: блок «Лидеры клуба» берёт реальный рейтинг (вместо заглушки); опционально список
      игроков турнира на табло.

## Этап 3 — для игроков (нужен выход в интернет)
- [ ] Публичная страница рейтинга / Telegram-бот или Mini App: рейтинг, анонсы, запись на турнир.
      Ноутбук из интернета недоступен → вариант: публикация рейтинга на дешёвый VDS
      или через Tailscale. Решение — с владельцем.

## Этап 4 — по необходимости
- [ ] Финансы смены: оплаты входов/аддонов, бар игрока, долги, закрытие смены, отчёт за день/месяц.
- [ ] Бар: меню, заказ на игрока, остатки.
- [ ] Роли: владелец / администратор турнира (разные пароли и права).
- [ ] Шаблоны турниров по дням недели, расписание.

## Не делаем (пока)
Призовые места на табло, рассадка по столам и дилеры, официанты и доставка, RFV/LTV-аналитика,
прогнозы выручки, канбан задач.
