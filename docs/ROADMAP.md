# План: система управления клубом ГОТО ПОКЕР

Ориентир — функции ELO Club (eloclubcrm.store): CRM игроков, турниры по игрокам, серии и рейтинги
ELO/CP/KO, финансы смены, бар, приложение игрока. Повторяем **не всё**, а по этапам —
то, что реально нужно клубу. Сейчас — ноутбук в баре (временно), цель — VDS + Telegram-бот/Mini App.

**Профиль клуба (от владельца):** до 3 столов на турнир; оплата — наличные и карта (терминал);
есть бар (учитывать позже); игроки — в Telegram и ВКонтакте. Приоритет: **рейтинг** важнее финансов.

      Схема сразу содержит таблицы под игроков, участников, вылеты/KO, периоды и финалы.

      Тесты итогов и рейтинга — вместе с Этапами 1–2.
- [x] Резервная копия базы: при каждом запуске и завершении турнира копия в `data/backups/`
      (по 30 каждого вида). Windows-пакет пересобран и проверен на Node 22.

## Этап 1 — игроки и турнир по игрокам (ядро) ✅ (30.10.2026, ветка etap-1/players)
- [x] База игроков: имя/ник, телефон (обязателен, без дублей), заметка, дата первого визита.
      Быстрый поиск (имя, последние цифры телефона), добавление нового игрока прямо из турнира.
- [x] Участники турнира: запись заранее и «Пришёл» (= вход), re-entry, аддон или двойной аддон
      (один на игрока); вылет в 2 касания с «кто выбил», делёж банка (по 0,5), несколько в одной
      раздаче (по стеку / равные стеки), без нокаута; отмена действий.
- [x] Счётчики табло считаются из участников автоматически (режим «По игрокам»;
      ручной режим остался запасным).
- [x] Итоги турнира: завершение, дил на финальном столе, история турниров, исправление итогов
      с записью в журнал.
- [x] Простая рассадка: стол 1–3 / место 1–10 у участника, без автобалансировки.
- [x] Всё удобно с телефона (проверено на ширине 375 px).

## Этап 2 — серии и рейтинг (правила — `docs/RATING.md`)
- [ ] Серии (лиги) с правилами: какие показатели считаются (CP, баллы за места, KO, посещения),
      период, какие турниры входят. Один турнир — в нескольких сериях.
- [ ] Начисление очков по `docs/RATING.md`: баллы за место × √(игроков/20) × статус
      + 5 за KO − 5 за re-entry; все числа — настройки.
- [ ] Периоды: кнопка «Закрыть период» → финалисты топ-N (N меняется в любой момент) →
      финал месяца → новый период стартует после финала. Сезон/год — аналогично.
- [ ] ELO-рейтинг игроков (отдельный показатель, см. `docs/RATING.md` §4).
- [ ] Страницы рейтинга: по серии, за месяц, за всё время; карточка игрока с историей.
- [ ] Табло: блок справа по очереди показывает рейтинг месяца, за всё время, игроков турнира
      с нокаутами и «сколько очков даст место сейчас» (`docs/RATING.md` §7).

## Этап 3 — переезд на VDS и Telegram для игроков
- [ ] Переезд системы на VDS (скрипты `deploy/` готовы): табло в клубе открывается через интернет,

- [ ] Публичная веб-страница рейтинга (ссылка для ВК и сайта клуба).
- [ ] Достижения игроков («10 турниров», «первая победа» и т.п.) — поверх истории.

## Этап 4 — по необходимости (после рейтинга)
- [ ] Финансы смены: оплаты входов/аддонов (наличные / карта), долги, закрытие смены, отчёт за день/месяц.
- [ ] Бар (подтверждено владельцем, но позже): меню, счёт игрока, остатки.
- [ ] Роли: владелец / администратор турнира (разные пароли и права).
- [ ] Шаблоны турниров по дням недели, расписание.

## Не делаем (пока)
Призовые места на табло, автоматическая рассадка/балансировка столов и экран дилера (столов ≤ 3), официанты и доставка, RFV/LTV-аналитика,
прогнозы выручки, канбан задач.
