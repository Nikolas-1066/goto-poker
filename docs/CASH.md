# Касса турнира — правила (утверждены владельцем 30.10.2026)

Касса работает только в режиме «По игрокам». В ручном режиме («Вручную») — без изменений.
На очки рейтинга и ELO касса не влияет.

## Цены

- Цены в рублях: **вход**, **re-entry**, **аддон**, **двойной аддон** — задаются в пресете.
- В идущем турнире цены можно поправить (например, акция). Правка действует на новые действия.
- Каждое действие (вход, re-entry, аддон) запоминает свою цену в момент нажатия —
  поменяли цены позже, уже начисленное не меняется.

## Начисления

- «Пришёл» начисляет цену входа, «Re-entry» — цену re-entry, «Аддон» / «Двойной аддон» — свою цену.
- Отменили действие — начисление снимается вместе с ним.
- **Бесплатно**: админ вручную отмечает конкретный вход / re-entry / аддон как бесплатный
  (и может снять отметку). Бесплатное действие на счёт не идёт, в итогах считается отдельно.

## Оплата

- Способы: **наличные**, **карта**, **перевод**.
- Оплата частями — несколько оплат (1 000 наличными + 500 картой).
- Ошибочную оплату можно отменить.
- Сумма оплаты — не больше долга. Если вход отменили после оплаты, у игрока «переплата» —
  её убирают отменой оплаты (вернули деньги) или игрок снова входит.
- «Сбросить турнир» стирает входы, но не оплаты: деньги уже в кассе.
- Игрока с оплатой нельзя убрать из записи — сначала отменить оплату.
- Плашка у игрока: «Оплачено» или «Должен N ₽».

## Долги

- Не доплатил — долг остаётся на карточке игрока (сумма по всем турнирам).
- При записи на следующий турнир админ видит «Долг N ₽ с турнира ДД.ММ» и может принять оплату.
- Завершить турнир с долгами можно — система только предупреждает, сколько игроков и на какую сумму.

## Итог кассы

По каждому турниру: начислено, бесплатно, собрано (наличные / карта / перевод), кто сколько должен.
