# Сайт клуба и мини-приложение в Telegram — план (утверждён владельцем 13.11.2026)

Ориентир — приложение игрока в ELO Club (eloclubcrm.store). Правила записи — из обсуждения Этапа 3.

## Решения владельца

- **Сервер — основной.** База одна, на VDS (Timeweb, Россия). Табло и админка клуба открываются через интернет.
  Ноутбук-пакет остаётся запасным вариантом без интернета.
- Сервера и домена пока нет — владелец покупает по `DEPLOY.md`, пароли в чат не присылает.
- **Сайт для всех (без входа):** расписание и запись, рейтинг, итоги турниров, о клубе.
  Публично — только имена, места, очки. Телефоны, касса, долги — никогда.
- **Вход игрока:** через Telegram (в мини-приложении — сам, на сайте — кнопкой) **и** по логину и паролю.
  Привязка к базе клуба — по подтверждённому в Telegram номеру телефона.
  Логин и пароль (предложение, владелец согласился с планом): игрок задаёт сам в профиле после входа через
  Telegram; тем, у кого Telegram нет, выдаёт админ в карточке игрока. Свободной регистрации по номеру нет.
- **Запись на турнир:** можно «+1…+3» (гости занимают места), лимит мест — по желанию для каждого турнира,
  лист ожидания, отмена до начала.
- **Сообщения:** напоминание записавшимся утром в день турнира; анонсы — всем, с возможностью отписаться.
- Бота создаёт владелец через @BotFather (инструкция — на шаге 4).

## Шаги (каждый — рабочее состояние)

1. Сервер и домен: настройка, HTTPS, перенос базы с ноутбука.
2. Расписание турниров в админке: будущие турниры (дата, время, структура, цена, лимит мест).
3. Сайт клуба: расписание, рейтинг, итоги, о клубе.
4. Бот и мини-приложение: привязка по телефону, мой рейтинг, моя история, расписание.
5. Запись на турнир (+гости, лист ожидания, отмена); записавшиеся появляются в турнире в админке.
6. Напоминания и анонсы.
7. Вход по логину и паролю на сайте.

## Что не решено — спросить владельца

- Правила расписания (шаг 2): что задаётся у будущего турнира, повторяющиеся турниры по дням недели.
- Что игрок видит о себе: показывать ли ему его долг.
- Текст раздела «О клубе».
